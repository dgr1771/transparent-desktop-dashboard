# 「透明桌面看板」抖音短视频运营方案

> 目标：用项目开发过程做内容，涨粉。核心打法：**效果演示引流 + 开发故事留人**，
> 系列化更新，每条视频都是一个"钩子"。

## 二、内容策略：两条内容线交替发

**A 线：效果演示（涨播放）**——15~30 秒，前 3 秒必须是桌面全景反差画面。
**B 线：开发故事（涨信任/粉）**——30~60 秒，讲"这个功能我怎么做的/踩了什么坑"。

节奏：**A、A、B、A** 循环，每 2~3 天一条，固定时间发（12:00-13:00 或 18:00-20:00）。

## 三、前 6 集脚本（直接复制）

### 第 1 集（A 线·引流款）"你的桌面还在贴便签吗？"

- **标题**：我花了 3 个月，把 Windows 桌面改成这样了
- **封面文案**（大字）：`把桌面还给壁纸 +1` 或 `这桌面是长在壁纸上的`
- **时长**：25~30 秒
- **分镜 + 口播稿**（逐字）：

| 画面 | 口播/字幕 |
|---|---|
| 0-3s：桌面全景缓慢推近（时钟/天气/股票全在壁纸上） | "这些不是软件窗口——它们长在我的壁纸上。" |
| 3-8s：鼠标从时钟上划过，点桌面正常选中图标 | "鼠标点不到它，因为它会自动穿透，跟壁纸一样。" |
| 8-15s：点桌面底部卡堆→扇形展开→抽一张牌飞入桌面变新闻卡 | "想加功能？像抽卡一样，抽一张，它自己飞到桌面上。" |
| 15-22s：快速闪现：天气特效下雨/股票红绿/新闻 AI 摘要 | "天气、股票、新闻，还有 AI 自动帮我总结新闻。" |
| 22-27s：按 Win+D，其它窗口全消失，看板还在 | "按显示桌面，所有窗口都藏了，就它藏不住。" |
| 尾帧：账号名+"开源免费"字样 | "开源免费，想要的评论区扣个**桌面**。" |

- **话题标签**：#桌面美化 #windows11 #效率工具 #程序员 #开源项目 #科技桌面 #电脑技巧
- **BGM**：抖音商用音乐库搜"科技感 卡点"，卡在扇形展开那一帧

### 第 2 集（A 线）"我给桌面做了个抽卡系统"

- **标题**：给桌面装了个抽卡系统，出金是新闻卡
- **封面文案**：`桌面抽卡 出金✨`
- **时长**：20 秒
- **分镜**：0-3s 手指点击卡堆特写 → 3-8s 18 张牌扇形展开（风铃声完整收录！）→ 8-14s 翻牌看牌面+今日运势金卡+粒子迸发 → 14-18s 抽一张牌飞入落位 → 尾帧"你抽到什么，评论区报一下"
- **口播要点**：全程少说话，让音效说话；只说"每张牌是一个功能，抽到就上桌，还有每日运势"
- **标签**：#抽卡 #桌面美化 #仪式感 #程序员日常 #windows

### 第 3 集（B 线·开发故事）"鼠标为什么点不到它"

- **标题**：为什么鼠标点不到我的桌面小组件？
- **封面文案**：`鼠标穿透 是怎么做到的`
- **时长**：40~50 秒
- **口播稿**（逐字，语速平缓）：
  > "很多人问我，鼠标划过这些卡片，为什么不会点到它们？
  > 其实原理就一句话：Windows 有个 API，叫 SetWindowLong，给窗口加一个'穿透'标志位，鼠标事件就会直接落到下一层。
  > 但真做起来没那么简单——卡片要能点，空白要穿透，所以我让程序实时判断：鼠标在哪，指的这块是不是卡片，逐帧切换穿透开关。
  > 最坑的是 Windows 更新后这套全变了，我重新适配了三天。
  > 关注我，下期讲怎么让桌面卡住 Win+D 不被藏起来。"
- **画面**：口播时屏幕演示——鼠标划过卡片 vs 点空白选图标；结尾闪一下源码编辑器画面
- **标签**：#程序员 #windows原理 #electron #编程 #技术宅

### 第 4 集（A 线）"我的桌面会下雨"

- **标题**：桌面下雨了，但我的壁纸没事
- **封面文案**：`桌面下雨☔（壁纸没湿）`
- **时长**：15 秒，纯效果+音乐，口播只留开头一句："下雨了——在我的桌面上。"
- **画面**：天气特效全屏雨滴 5s → 切雪 5s → 切晴天阳光 5s，尾帧"天气联动，自动切换"
- **标签**：#桌面美化 #治愈 #下雨 #氛围感

### 第 5 集（B 线）"看板天天闪退，我挖了三天日志"

- **标题**：我的软件天天闪退，最后靠这招抓到真凶
- **封面文案**：`闪退抓凶实录🔍`
- **时长**：50 秒
- **口播稿**：
  > "我的看板软件总是莫名闪退，日志里干干净净什么都没有。
  > 后来我学了一招：去 Windows 事件查看器里挖——真有记录！异常代码 0x80000003，这是程序底层直接崩了，普通日志根本接不住。
  > 于是我给程序加了四层'黑匣子'：崩溃转储、子进程监控、退出码记录……
  > 现在再闪退，5 分钟就能定位到是哪一行出的事。
  > 做软件就是这样，功能只占三成，剩下七成都在跟 bug 斗智斗勇。"
- **画面**：事件查看器滚动截图 → 代码 diff 画面 → main.log 特写
- **标签**：#程序员日常 #debug #bug #软件开发 #码农
- **备注**：这集素材就是真实经历（今天刚发生的闪退），真实感是 B 线的核心

### 第 6 集（A 线·转化款）"三步装上同款桌面"

- **标题**：三步，把这个桌面装到你电脑上
- **封面文案**：`同款桌面 三步拿走`
- **时长**：40 秒
- **分镜**：①打开 releases 页下载安装包（录屏 10s）②双击安装，桌面长出时钟（10s）③右键托盘选布局/设置里换主题色、切抽卡模式（15s）→ 尾帧"GitHub 仓库在评论区置顶"
- **口播**：照分镜念步骤即可，语速慢一点
- **标签**：#桌面美化 #教程 #windows技巧 #开源
- **发布后**：置顶评论放 GitHub 链接 + "卡在某一步评论区问我"

## 四、拍摄与剪辑实操（一次性配置好）

### 录屏（OBS Studio，免费）
1. 来源加"显示器采集"，分辨率 1920×1080，帧率 60
2. **重要**：录之前把桌面图标收拾干净、壁纸换成深色纯色/星空——看板是主角，别抢戏
3. 录的时候所有操作放慢 20%，鼠标移动轨迹要稳（观众跟着你的鼠标走）

### 竖屏适配
- 抖音是 9:16 竖屏，桌面是 16:9 横屏——**直接满屏放会变小**
- 剪映里：横屏素材放中间，上下加模糊放大的同画面做背景（剪映一键"画中画模糊背景"）
- 或者：局部放大录制（OBS 来源裁剪到时钟/天气区域），特写更有冲击力

### 剪映流程（每条 15 分钟）
1. 导入素材，掐头去尾只留有效动作
2. 自动识别字幕 → 统一字体（推荐"新青年体"），字号大、位置中下
3. 关键动作加 0.5 倍速慢放（抽卡展开、粒子迸发）
4. BGM 用抖音内置商用曲库（避免版权问题），音量压到人声的 30%
5. 封面：选信息量最大的一帧 + 加大字标题

## 五、评论区运营（涨粉的一半在这里）

1. **每条视频埋一个"扣字钩子"**："想要的扣桌面"——评论数是抖音推流的核心指标
2. **置顶自评**：预埋"问：支持 Win10 吗？答：支持！"这类 FAQ

4. **反面评论也是素材**："这不就是 Rainmeter？"→ 下期做对比视频（蹭已有热度）
