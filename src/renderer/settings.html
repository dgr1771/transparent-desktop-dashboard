⚙️ 设置

配置数据源与显示选项。修改后点击"保存"生效。

🌤️ 天气

首次启动会自动定位。也可点"自动定位"重新获取当前位置。
免费申请：dev.qweather.com（注册后在控制台创建项目获取 Key）
若天气报"Invalid Host"错误，请填写和风控制台 → 应用设置 → API Host 里显示的域名。2024 年后注册的账号通常需要填这个。

📈 A股自选

沪市 sh + 6位代码，深市 sz + 6位代码。例：sh000001（上证指数）、sh600519（贵州茅台）

📰 新闻 RSS 源（中文）

推荐中文源：量子位、少数派、36氪、机器之心。可在 RSSHub 找到更多中文媒体 RSS。
